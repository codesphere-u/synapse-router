Protocol & Policy Reference

6 MCP Tools & Aegis G2 Routing Gates

TOOL · route_agent_step

Route Agent Step Across Tiers

Evaluates Pareto cost/latency, SimHash cache, circuit breakers, and confidence escalation returning a signed receipt.

TOOL · classify_task_complexity

Classify Complexity Score & Tier

Computes deterministic [0.0, 1.0] complexity score and assigns FAST_LOCAL, BALANCED, or FRONTIER_REASONING.

TOOL · inspect_endpoint_health

Inspect 3-State Circuit Breaker Health

Reports CLOSED / OPEN / HALF_OPEN status, error rate, and EMA latency per model endpoint.

TOOL · check_budget_status

Check Tenant & Workflow Budget

Evaluates 80% soft-cap tier downgrade and 100% hard-cap enforcement for tenant workflows.

TOOL · synapse_rate_limit_status

Sliding-Window RPM/TPM Status

Inspects rolling 60s request and token saturation with exact retry_after_seconds.

TOOL · synapse_export_aegis_g2

Export Nexus Aegis G2 Leaf

Produces RFC 6962 domain-separated (0x00) SHA-256 leaf digest and budget/tier policy attestation.

G2 · USD_BUDGET_CAP

Hard USD & 80% Soft-Cap Downgrade

Rejects executions exceeding budget_cap_usd and downgrades tiers automatically above 80% utilization.

G2 · TOKEN_CEILING_120K

120,000 Token Step Ceiling

Flags single-step runaway context consumption above 120,000 tokens.

G2 · ANTI_OVERPROVISIONING

Anti-Overprovisioning Guardrail

Blocks routing trivial tasks (ping, echo, lowercase, format JSON) to expensive frontier reasoning models.

RESOURCE · synapse://endpoints/catalog

Registered Model Endpoint Catalog

Lists configured endpoints, tier mappings, token prices, and capabilities.

RESOURCE · synapse://health/summary

Circuit Breaker Health Summary

Live availability, failure counts, and EMA latency across all endpoints.

PROMPT · route-task-advisor

Task Routing Tier Advisor

Recommends optimal tier and fallback cascade from prompt complexity and latency SLA.

PROMPT · budget-allocation-planner

Workflow Budget Planner

Designs token quotas, 80% downgrade rules, and 429 failover thresholds for multi-step workflows.
